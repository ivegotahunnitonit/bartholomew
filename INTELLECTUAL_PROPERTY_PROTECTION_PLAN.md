### Pillar 4: The Elastic / Redis Commercial Licensing Playbook (Anti-Cloud Free-Riding)
* **The Strategy**:
  - **Client SDKs (`btp-guard`)**: Permissive Apache-2.0 (so every developer in the world can install and use it freely).
  - **Core Enterprise Engine & Cloud Mesh**: **Business Source License (BSL 1.1)** or Commercial Enterprise License.
* **What this prevents**: Prevents Amazon Web Services (AWS) or Microsoft Azure from taking our code, hosting it as "AWS Agent Guard," and selling it without paying us licensing fees.

Is the local core runtime really 100% free forever?
Yes. Bartholomew's in-process AST gating, in-flight secret scrubbing, and local framework adapters are 100% open-source (Apache 2.0) and free forever. Paid plans ($49/mo Pro, $199/mo Enterprise) are strictly for multi-tenant workspace management, real-time SecOps alerting webhooks, self-healing rule synthesis, and certified auditor-signed SOC 2 Type II evidence generation.
Does license verification introduce execution latency?
No. All licenses are signed with Ed25519 asymmetric cryptography and verified locally in CPU memory in under 0.2µs. Bartholomew never "phones home" synchronously during agent tool execution, ensuring zero cloud lag.
Can Bartholomew run in isolated / air-gapped VPCs?
Yes. The core architecture runs 100% in-process as an embedded library with zero background daemons and zero open network sockets. It is fully deployable in air-gapped Kubernetes clusters and isolated enterprise VPCs.
Can I cancel, upgrade, or switch tiers anytime?

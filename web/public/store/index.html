Is the local runtime 100% pro bono & free?
Yes! Bartholomew's local execution gateway, AST syntax gating, in-flight secret scrubbing, rollback sandbox, and MCP proxy are 100% free and open-source forever (pro bono publico). Subscriptions ($49/mo Pro, $199/mo Enterprise) are strictly for commercial team cloud policy sync, SIEM ingestion, and certified auditor-signed SOC 2 Type II & ISO 27001 compliance evidence generation.
Does verification cause latency?
No. All licenses are signed with Ed25519 and verified locally in CPU memory in under 0.2µs. The software never "phones home" during agent tool execution.

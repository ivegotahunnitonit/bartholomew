Privacy Policy

Last Updated: August 15, 2026

1. Overview

Bartholomew AI ("we", "our", or "the Extension") is an autonomous developer copilot designed to help software engineers diagnose CI/CD failures, synthesize reproduction tests, and refactor code directly within the browser and GitHub.

We respect your privacy and are committed to protecting your personal data. This Privacy Policy outlines our data collection, usage, and storage practices.

2. Data Collection & Privacy First Architecture

Bartholomew AI is built on a privacy-first, client-side evaluation model:

  • No Personal Identifiable Information (PII): We do not collect, store, sell, or monetize your personal information, browsing history, identity, or private credentials.
  • No Background Tracking: The extension does not track your general browsing activity. Content scripts activate exclusively on explicit developer interactions (such as clicking the diagnosis badge or highlighting code on GitHub).
  • No Remote Code Execution: All extension logic is packaged and verified locally within the browser bundle.

3. Permissions & Data Usage Disclosures

  • activeTab: Used strictly when you trigger a diagnostic command on a GitHub tab to parse visible error logs or pull request diffs.
  • storage: Used locally in your browser to retain user interface preferences and selected assistant mode.
  • sidePanel: Used to render the interactive developer companion inside your browser's native side panel.
  • contextMenus: Used to provide quick right-click actions ("Ask Bartholomew to Explain Code").
  • host_permissions: Required to interact with GitHub pages upon user invocation and connect to your local Bartholomew daemon at http://localhost:8080.

4. Third-Party Data Sharing

We do not share, sell, transfer, or distribute any user code, tokens, or repository metadata to third parties, advertising networks, or data brokers.

5. Open Source & Transparency

Bartholomew is developed openly. You can review the architecture, repository files, and release artifacts directly on GitHub at github.com/ivegotahunnitonit/bartholomew.

6. Contact

If you have any questions or feedback regarding this Privacy Policy, you can open an issue on our official repository or contact us via GitHub: @ivegotahunnitonit.

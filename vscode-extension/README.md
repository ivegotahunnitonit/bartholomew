## 🛡️ Core Capabilities
- **Sub-25µs In-Process AST Gating**: Drops `rm -rf`, `DROP TABLE`, and destructive terminal attacks before OS execution.
- **In-Flight Secret Redaction**: Zero prompt leakage—automatically scrubs OpenAI, Anthropic, AWS, GitHub, and Stripe keys.
- **Model Context Protocol (MCP)**: Native secure tool gateway for Claude Desktop and Cursor.
- **Cryptographic Merkle Receipts**: Append-only tamper-evident compliance audit trail for every agent action.

## 🚀 Usage in Cursor / VS Code
- Press `Ctrl+Shift+P` (or `Cmd+Shift+P` on macOS) and run:
  - `Bartholomew: View Security Status & Trust Roots`
  - `Bartholomew: Upgrade to Pro (Cloud Telemetry & Slack Alerts)`
  - `Bartholomew: Validate & Lint Workspace Security Policy`
  - `Bartholomew: Generate SOC 2 / ISO 27001 Evidence Pack`

# Bartholomew Autonomous AI Guard (BTP v3.0)

Sub-35µs in-process tool execution gateway, AST policy dry-run linter, and offline Merkle receipts for Cursor and VS Code.

## Features
- **In-Process AST Gating**: Intercepts `rm -rf`, `DROP TABLE`, and destructive commands before OS execution.
- **In-Flight Secret Redaction**: Scrubs OpenAI, Anthropic, AWS, and Stripe tokens.
- **Model Context Protocol (MCP)**: Native security boundary for Claude Desktop and Cursor.
- **SOC 2 Type II Receipts**: Stamped Merkle roots on every agent turn.

## Usage
- Run `Bartholomew: View Security Status & Trust Roots` from the Command Palette.
- Run `Bartholomew: Generate SOC 2 / ISO 27001 Evidence Pack`.

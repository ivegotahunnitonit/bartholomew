Enterprise Security & Compliance Model

Hardened multi-layer security architecture protecting against network isolation, poisoning, and unauthorized access.

Infrastructure Hardening

UFW firewall restricts incoming ports, Fail2ban mitigates brute force attacks, and Nginx enforces strict rate limits (10 req/s, burst 20).

HMAC Gossip Signing

Every P2P listing and node message is signed via `x-acn-signature` HMAC-SHA256 header, preventing DNS/routing poisoning.

DePIN Physical Attestation

Hardware sensors generate cryptographic GPS and scale weight signatures every 20s to eliminate phantom listing fraud.

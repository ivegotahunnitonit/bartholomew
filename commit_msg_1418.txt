fix: reconnect conflict-resolution / validation path (issue #1418)

The "reconciles contradictions" feature was documented in Memanto's whitepaper
(arXiv:2604.22085 Sec. E) and memanto.ai as a core differentiator, but the
entire validation pipeline was silently bypassed on main / v0.2.4.

Root causes found and fixed:

1. ValidationPolicy removed from core.py
   `memanto/app/legacy/memory_validation_service.py` still imported
   `ValidationPolicy` from `memanto.app.core`, but the class was deleted at
   some point without being reconnected — causing an ImportError and making
   the entire legacy validation module unimportable.

   Fix: Add a minimal `ValidationPolicy` class to `core.py` with:
   - `validate_memory(memory, context)` — checks `repetition_count` and a
     `conflict_detected` flag; returns `"store"` or `"store_provisional"`
     with the memory status set accordingly.
   - `make_provisional(memory)` — returns an immutable copy with
     `status = "provisional"`.

2. validation_service.validate_memory() call commented out
   Both `store_memory()` and `batch_store_memories()` in
   `memory_write_service.py` had the validation call commented out with a
   `# skip validation for speed` note and hardcoded
   `"MVP direct store"` bypass. Two contradicting memories of the same type
   (e.g. "deadline is April 15" then "deadline is April 22") would both be
   stored as `status="active"` with unchanged confidence, forever.

   Fix: Re-enable the validation call in both write paths. Added a
   `validation_service` lazy property to `MemoryWriteService` that
   instantiates `MemoryValidationService` on first use.

3. _check_repetition disabled in MemoryValidationService
   The repetition check (which queries Moorcheh for high-similarity existing
   memories before storing) was also commented out. Re-enabled with a
   graceful try/except so on-prem deployments without embeddings degrade
   cleanly instead of erroring.

Tests: added 7 unit tests verifying ValidationPolicy contract and that
store_memory() calls validation_service and honours the provisional flag
(66 total, all pass).

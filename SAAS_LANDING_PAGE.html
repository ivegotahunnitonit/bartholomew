How Bartholomew Works

Three deterministic steps replace guessing with guaranteed correctness.

01 / Core Loop

Catch, Isolate, and Reproduce the Exact Failure

The moment your GitHub CI workflow fails, Bartholomew ingests the webhook and clones the broken commit into a fully isolated sandbox environment. It synthesizes a standalone reproduction script that proves the defect is real and reproducible — zero guessing.

02 / Patch Engine

Minimal Surgical AST Patch

Instead of rewriting entire files, Bartholomew uses compiler-level AST analysis to compute the smallest possible change that resolves the root cause with zero collateral modifications.

03 / Verification

100% Test Suite Confirmation

Every single test in your suite runs against the proposed patch locally. Only when all tests pass with zero regressions does Bartholomew open the Pull Request.

04 / Delivery

Verified Green PR Ships Automatically

A clean, reviewed, and instantly mergeable Pull Request appears in your repository with reproduction evidence attached. Your team wakes up to a resolved pipeline.

            Sovereign Enclave Security Architecture
          

          

            Bartholomew was architecturally designed for sovereign enclaves. The Go engine (bartholomew_daemon.exe) has zero external dependencies. It is a single binary, compiled from stdlib-only Go code. It requires no internet connection, no API keys, no cloud services, and no package managers to operate.
          

          

            

              
No External Calls

              
All 7 OWASP detection classes use compiled regex patterns. No ML inference, no API calls, no cloud endpoints required.

            

            

              
Single Binary Deploy

              
One bartholomew_daemon binary. Deploy to air-gapped K8s, Docker on SCIF network, or bare metal. No pip, no npm.

            

            

              
Local Chain Persistence

              
SHA-256 chain writes to local append-only attestation.log. No Firestore, no cloud storage needed in sovereign mode.
